# Game Design Document

## 1. Core Loop

- Gather Resources

- Build
- Produce Army
- Contest Neutral Resources
- Raid Enemy
- Expand
- Destroy Enemy

## 2. Match Structure

**Early Game**

- 建立基础经济
- 建造第一个生产建筑
- 生产第一批军队

**Mid Game**

- 争夺地图资源
- 攻击中立单位
- 骚扰敌方经济
- 扩大军队规模

**Late Game**

- 资源争夺加剧
- 大规模战斗
- 摧毁敌方主城

## 3. Economy

### Gold

用途:

- 训练军事单位
- 升级

来源

- Goldmine
- Sheep (farming)

规则

- Worker必须移动到资源点进行采集
- Gold Mine提供高效率金币
- Sheep提供较低效率金币

### Wood

用途

- 建造建筑

来源

- Trees

规则

- 每个军事单位占用人口

  - 建造House增加人口上限

  - 到达上限后无法继续制造单位

- 训练军事单位需要军营建筑

  - 制造，升级

### Population

用途

- 每个单位占用人口
  - 军事单位
  - 建造单位

来源

- 建造新房屋、升级房屋

规则

- 建造House增加人口上限

- 到达上限后无法继续制造新单位
